## 🚀 Featured Projects

### 🤖 Multi-Tool Agent

An agentic system that routes questions to 3 tools (calculator, web search, RAG retrieval) via Groq function-calling, with a text-based fallback for malformed outputs. **100% routing accuracy** on a 10-question eval, 0 crashes, ~1.3s average response time.

### 📊 Data Analysis Agent

An autonomous agent that plans, generates, and executes pandas code to answer natural-language questions, with a self-correction loop that reads runtime errors and rewrites the code. **100% accuracy** on a 10-question verified test set (avg. 1.3 attempts).
